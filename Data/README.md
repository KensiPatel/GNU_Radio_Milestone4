# Data

This project uses no external dataset. All data is generated by the scripts in `../Code/src/gr-isac/scripts/`:
complex white Gaussian noise plus (where needed) one complex tone, with a fixed random seed.
The generated tables and figures are in `../Results/`.

(In M1 we planned to use the RadioML dataset for a classifier. The project changed to spectrum sensing in M2/M3, so RadioML is not used.)
